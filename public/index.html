Sobre o Sistema

Este sistema demonstra três formas diferentes de comunicação em tempo real entre servidor e cliente:

🔗 WebSocket

Conexão bidirecional persistente para atualizações instantâneas com menor latência.

⏱️ Long Polling

Requisições de longa duração mantidas vivas até haver atualizações.

🔄 Pooling

Requisições periódicas (polling) tradicionais em intervalos fixos.

📦 Arquitetura MVC

Código organizado em Models, Controllers, Routes e Utils.

💾 Persistência

Dados armazenados em JSON com sincronização em tempo real.

🎨 Design Responsivo

Interface adaptada para desktop, tablet e dispositivos móveis.

Funcionalidades Principais

✅ Criar Aula

Inicie uma nova aula para o dia atual com um clique.

👥 Marcar Presença

Registre presença individual ou em massa dos alunos.

📡 Sincronização

Atualização automática em tempo real para todos os clientes.

📊 Relatórios

Visualize histórico completo de aulas e frequências.

🔐 Persistência

Todos os dados são salvos permanentemente no servidor.

📱 Mobile Ready

Funciona perfeitamente em smartphones e tablets.

Tecnologias Utilizadas

Node.js Express WebSocket JavaScript HTML5 CSS3 REST API JSON
